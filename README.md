Сайт на двух языках, публикуется на Vercel из этого репозитория.

**Как обновить:** правки делаются в папке `src/`, затем `python3 src/build.py` собирает все страницы (русские и английские). Подробно — в `CLAUDE.md`.

**Как добавить проект:** новый объект в массив `PROJECTS` в `src/home.src.html` (каждый текст на `ru` и `en`), страницы кейса — рядом, файлы — в `files/`.
